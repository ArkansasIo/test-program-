# Changelog

All notable changes to the Railway Operations Control Platform are documented here.

## 2026-10-20 — Railway Platform Redesign

### Added
- Enterprise railway product identity and documentation model.
- 11 main railway menus.
- 44 stable railway page IDs.
- Typed railway API client and dispatch command contract.
- Railway control-room workspace and module navigation.
- Railway platform architecture, GUI, data-model, UML, release, and roadmap documentation.

### Changed
- Replaced former space-strategy/game documentation with railway operations terminology.
- Reframed combat as movement/regulation concepts.
- Reframed resources/economy as capacity and operational planning.
- Reframed mothership/fleet concepts as railway fleet control.
- Reframed stargate/network concepts as railway network infrastructure.
