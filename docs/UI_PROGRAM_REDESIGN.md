# Railway Control-Room UI Redesign

## Objective

Replace the former game/program command interface with an enterprise railway operations workstation.

## Main Navigation

1. Control Center
2. Timetable & Service
3. Network Infrastructure
4. Train Fleet
5. Stations & Terminals
6. Signaling & Control
7. Asset Maintenance
8. Crew Operations
9. Safety & Emergency
10. Performance Intelligence
11. Administration & Security

## Page Workspace

Each page contains:

- identity header
- operational status
- primary control surface
- contextual inspector
- action controls
- event/alert feed
- data freshness indicator

## Visual Hierarchy

Critical safety alerts outrank operational warnings. Operational state outranks analytics. Primary actions outrank secondary navigation. IDs and timestamps remain available to support audit and troubleshooting.

## Responsive Behavior

Desktop uses a three-pane control-room layout. Tablet converts the inspector to a drawer. Mobile stacks the main workspace and keeps critical commands and safety status accessible.
